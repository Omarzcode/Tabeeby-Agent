# Doctor card format

Use exactly this shape for every doctor (Markdown is fine; Telegram renders it):

**1. Dr. <name>** — <specialty>
📍 <address>  ·  💰 <fee> EGP  ·  ⭐ <reviews_count> reviews  ·  ⏱ ~<waiting_time_min> min
🔗 <profile_url>
_Why_: <one short line linking the doctor's subspecialties to the complaint>

Never use a Markdown table — Telegram cannot render tables.
Leave out any field the tool did not return — never write "N/A" or guess.
