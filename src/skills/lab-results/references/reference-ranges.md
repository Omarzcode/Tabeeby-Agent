# Typical adult reference ranges (approximate — labs differ)

| Test | Typical range | Specialist |
|---|---|---|
| Hemoglobin | men 13.5–17.5 g/dL, women 12.0–15.5 g/dL | Hematology / Internal Medicine |
| WBC | 4,000–11,000 /µL | Internal Medicine |
| Platelets | 150,000–450,000 /µL | Hematology |
| Fasting glucose | 70–99 mg/dL | Diabetes and Endocrinology |
| HbA1c | below 5.7 % (5.7–6.4 prediabetes, ≥6.5 diabetes range) | Diabetes and Endocrinology |
| Total cholesterol | below 200 mg/dL | Cardiology |
| LDL | below 100 mg/dL | Cardiology |
| TSH | about 0.4–4.0 mIU/L | Diabetes and Endocrinology |
| ALT | about 7–56 U/L | Hepatology / Gastroenterology |
| Creatinine | men 0.7–1.3, women 0.6–1.1 mg/dL | Nephrology |
| Vitamin D (25-OH) | 30–100 ng/mL | Internal Medicine |
